## 可观察行为

1. 素材库、素材详情/编辑/上传、数字人列表/档案/编辑、为指定数字人选择素材为明确页面状态。使用现有查询参数保留深链接；操作流不叠加大模态，不复制全站导航。小型删除/放弃草稿确认可以使用 HeroUI 弹层。
2. 素材卡片提供真实图片/视频预览、名称、类型、独立标签块、服务端引用数量。数字人列表可直接查看档案或为该对象添加素材；归档可恢复。
3. 添加页常显目标名称。默认 `excludeDigitalHumanId` 在服务端过滤已有引用后分页；取消“隐藏已选内容”显示勾选且禁用的已有项并注明目标。本轮新勾选不隐藏，不计入已有项。搜索覆盖名称/说明/标签，切类型/分页保留本次待添加清单。
4. 搜索下方左侧为隐藏开关，右侧为“本次新增 N 项 / 取消 / 确认添加(N)”。点击确认前不发送关联写入；每个待新增项仅关联一次，部分成功保留剩余项和明确反馈。切换对象不得沿用另一对象的草稿。
5. 添加页可以直接上传到当前数字人。往返上传保留原选择、筛选和目标；成功上传 C 不丢失先前勾选的 A/B。100% 传输与确认入库分开显示；入库成功、关联失败只重试关联。
6. 上传和编辑的标签使用 HeroUI TagGroup/Tag 多选，详情/卡片用 Chip。独立输入支持回车或按钮创建并自动选中；空白拒绝、重名复用；保存时处理尚未添加的非空输入。取消编辑不创建已保存标签，失败保留草稿。标签候选来自已保存的就绪素材，不建第二份全局字典。
7. 点击全局删除时重新读取引用。若仍有引用，显示不能删除的原因、引用者（含归档）及档案入口；不提供可执行的确认删除。API 同样拒绝，且不调用对象存储删除。全部解除后才能重新确认并删除。确认期间新增引用也必须由事务检查拒绝。

## 接口与兼容性锁定

- 复用 `GET /v2/media/assets?excludeDigitalHumanId=...`，不在客户端过滤当前页来伪造 total。
- 扩充 keyword 搜索，使标签也可命中。标签精确筛选需支持所有合法已保存标签，不引入与现有元数据矛盾的长度限制。
- 新增只读 `GET /v2/media/assets/tags`，返回就绪、未删除素材的去重标签字符串数组，作为候选；按现有 readonly/路径约定实现，在动态详情路由前注册。
- `POST /assets/upload-url` 增加可选 `tags` 数组，默认空；在原票据事务中保存，不增加上传后补写元数据的失败阶段。旧调用继续有效。
- 素材列表/详情增加服务端 `usageCount`（JSON camelCase；Python 内部 snake_case）用于卡片展示，不通过下载全部档案前端聚合。扩充既有 decoder 并保留旧 fixture 可解析性。
- 引用中 DELETE 返回 `409`、稳定 `detail="ASSET_IN_USE"`；前端映射清晰原因并重新读取最新引用，不把 409 当成功。不改变原 auth/CSRF/破坏操作 guard，不增加强制删除参数。
- repository 删除前获得资产排他行锁，之后在同一事务检查活跃引用；既有关联的资产共享行锁与之互斥。查询含归档、排除已删除档案；删除被拒绝时数据、关系及存储字节保留。
