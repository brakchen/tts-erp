# tts-erp 领域语言

tts-erp 汇集 TikTok Shop 销售、广告、结算、售后与采购事实，用统一业务口径支持运营分析。

## 盈利分析

**SPU 盈利**：
以 v10 口径衡量单个 SPU 的经营结果；同时纳入净收入、广告消耗、采购成本、退款、海外取消与全损。它是项目中“SPU 盈利”的唯一权威含义。
_Avoid_: 用“SPU 盈利”指代只做销售额减采购成本的粗略毛利

**SPU 盈利明细**：
在同一 v10 盈利口径下，只针对某一个 SPU 得出的经营结果。
_Avoid_: 店铺大盘、单纯的订单或广告明细

**盈利大盘**：
在同一 v10 盈利口径下，针对范围内所有 SPU 得出的整体经营结果；订单级事实按整体范围去重，不能把 SPU 盈利明细简单相加。
_Avoid_: SPU 行合计、分页合计

**盈利证据**：
用于解释某个 SPU 盈利结果的订单、结算、售后与广告事实；它支撑结果，但不等同于盈利结果。
_Avoid_: SPU 盈利明细、盈利大盘

**盈利范围**：
决定 SPU 盈利明细与盈利大盘共同计算范围的店铺、日期窗口和商品状态选择；文本搜索、排序与分页只影响明细展示，不改变盈利大盘。
_Avoid_: 把当前搜索结果或当前页当作盈利大盘

**实时盈利结果**：
按计算时点同一个一致数据快照中的最新业务事实得出的 v10 SPU 盈利结果，并明确携带计算时点；不同请求可因约十分钟级的数据同步而有细微差异。
_Avoid_: 盈利日报、历史盈利快照、同一结果内混用不同数据时点、把跨请求差异称为强一致性失败

**盈利依据**：
随实时盈利结果一起说明实际数据与估算数据来源的信息，包括成本来源、结算覆盖、汇率时点和兜底使用情况；估算值只有在盈利依据明确时才是有效的 v10 结果。
_Avoid_: 不标注来源的估算利润、把估算值称为实际值

**汇率快照**：
数据库中保存的汇率事实，是 v10 盈利金额换算的必备依据；不存在可用汇率快照时，盈利结果不可计算，不能用固定常量代替。
_Avoid_: 编译期固定汇率、无来源的兜底汇率

**盈利展示币种**：
SPU 盈利的所有金额统一以人民币 CNY 计算和输出；广告原生 USD、销售与退款原生 VND 必须先按同一汇率快照换算为 CNY，采购成本保持 CNY。ROI、退款率等无量纲比例不做币种换算。
_Avoid_: 把 API 金额解释为 USD、在前端再次换汇、混合不同汇率快照

**粗略毛利快照**：
历史报表概念，仅表达销售额减采购成本，不包含完整的广告、结算、退款与全损语义，因此不等同于 SPU 盈利。
_Avoid_: SPU 盈利、实际利润

**实际 ROI**：
SPU 盈利中的投放效率指标，等于扣除全损成本后的净收入除以广告消耗；它不是“SPU 盈利”的同义词。
_Avoid_: SPU 盈利、净利润

**广告系统实际 ROI**：
广告系统视角下的投放效率，等于广告归因 GMV 除以广告实际消耗；它与财务实际 ROI 的分子不同，必须在盈利大盘和 SPU 盈利明细中独立展示。
_Avoid_: 财务实际 ROI、净利润率

**广告系统保本 ROI**：
广告系统视角下独立推算的保本阈值，等于广告归因 GMV 除以最大可承受广告费；当前缺少结算外必要成本时必须标记为 `estimated_known_costs`，页面以 `≈` 明示估算。
_Avoid_: 财务实际 ROI、把已知成本下限估算解释为最终保本线
