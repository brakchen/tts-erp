# SPU ROI

## 目的
按店铺和经营日期查看全量或指定范围内 SPU 的盈利大盘与明细，口径为 v10。

## 角色
系统管理员、运营、只读分析均可进入。本页以查询为主。

## 主流程
1. 选择店铺。未手选日期时，默认店铺当地「昨天」。
2. 需要时用快捷日期、预测样本（30 / 90 天）、临时佣金费率、「含无活动 SPU」缩小或放宽范围。
3. 可用 SPU ID / 标题搜索后「查询」限定精确范围（最多 100 个，含已选项）；清空则回到默认活动范围。精确选择会同时约束当前大盘和预测大盘。
4. 阅读经营概览（当前 vs 预计最终）、销售 / 采购价格统计、数据更新和商品明细。
5. 点击行下钻证据；打开「计算依据与数据说明」查看计算时间、口径版本、汇率快照等。

## 关键字段 / 筛选 / 操作
- 与重点关注页共用经营范围工具条和明细主列，见该页说明。
- **本页额外展示**销售价 / 实付价 / 采购价的均价、中位数与覆盖。采购价可能带 ≈（估算）。
- 明细同样不把「实际ROI」作为表格列，该指标在概览中展示。
- 地区无法确定报表时区时，提示先补充受支持的地区。

## 空态 / 错态
- 暂无可用店铺；原店铺不可用须重选。
- 起始日晚于截止日：保留输入并告警。
- 经营概览或同步时间加载失败：分区提示并可重试。
- 无汇率快照：整页不可算，不用固定汇率凑数。

## 验收要点
- 搜索、排序、分页不改变大盘。
- 预计最终只属于大盘，不作为单 SPU 行预测。
- 前端只渲染服务端结果；公式以 `docs/business/spu-profitability.md` v10 为准。

## 缺口
- 无独立「订单 / 售后 / 结算」菜单，证据只在下钻中。
- 旧表 `reporting.product_profit_daily` 不是本页真相源。
