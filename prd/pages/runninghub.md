# 换装视频

## 目的
选择服装图与人物模板（来自数字人已挂载的参考视频），按批次向 RunningHub 生成成片并下载。

## 角色
系统管理员、运营可进入本页（绑定 `page:runninghub`）。普通只读可见部分状态；**检查 / 保存工作流、账户与部分恢复类操作需 admin**。生成会发起计费任务。

## 主流程
1. 从资产管理中的就绪服装图里勾选图片，填写款式 / SKU；选择或新建人物模板并排好参考视频顺序。
2. 预览生成计划，可选择「仅跑首段」。
3. 确认「会产生 RunningHub 费用」后保存批次，再在批次记录中启动。
4. 查看成片、下载单段或整批 ZIP；可终止、在首段完成后续跑剩余段，或对失败任务恢复 / 重试。

## 关键字段 / 操作
- 服装图搜索与勾选、人物模板、仅跑首段、确认生成计划。
- 批次表：批次、状态、成片进度、操作（查看、下载、暂停、续跑等）。
- 工作流配置：凭据引用、显存档位、云端并发、工作流 JSON、检查账户 / 保存版本（admin）。

## 空态 / 错态
- 没有就绪图片或人物没有参考视频时，引导去资产管理 / 数字人补充。
- 未检查并保存工作流版本时，不能按完整路径启动（以页面提示为准）。

## 验收要点
- 启动前必须有费用确认，不能静默计费。
- 这是向第三方云端发起任务，不是改 TikTok 订单。

## 缺口
次级失败恢复未逐条核对全部夹具。具体计费以 RunningHub 侧为准，本系统只做确认提示。
