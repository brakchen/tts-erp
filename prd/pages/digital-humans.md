# 数字人

## 目的
维护数字人档案、形象照片，并关联公共素材包（以及一套较旧的单条素材关联入口），为换装视频提供人物与参考素材。

## 角色
系统管理员、运营可进入。写入需 readwrite。

## 主流程
1. 按状态（启用中 / 已归档 / 全部）浏览档案卡片。
2. 新建档案（名称、人设说明），上传或更换形象照片，编辑资料。
3. 打开档案后挂载已有素材包，或新建后立即关联；也可使用较旧的「关联素材」入口（解除关联不影响全局库和其他档案）。
4. 归档可恢复；删除档案会去掉关联，但全局素材文件保留。

## 关键字段 / 操作
- 列表：状态筛选、新建、形象照、查看档案、编辑、归档 / 恢复、删除。
- 档案内：素材包区、添加 / 移除素材（旧入口）。

## 空态 / 错态
- 当前没有档案，或暂无已归档档案。删除 / 归档需确认。

## 验收要点
- 两处看到同一份素材包。归档保留关联，可恢复。

## 缺口
「素材关联」旧入口与素材包新区并存，产品上需避免运营误判为两套互不相通的库（实现上全局文件仍共享）。
