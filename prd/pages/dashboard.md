# 控制台

## 目的
登录后的经营全局入口，查看数据覆盖、同步健康和常用工作入口。

## 角色
系统管理员、运营、只读分析均可进入。快速导航只显示当前用户有权进入的页面。

## 主流程
1. 查看快速导航，跳转到采购、SPU ROI、店铺、拦截配置、运行配置或广告日明细（视权限而定）。
2. 阅读数据摘要：待录成本 SPU 数、已跟踪 SPU 总数、已注册店铺数，并可跳转对应页。
3. 浏览已注册店铺精简表（名称、店铺 ID、地区、平台）。
4. 查看系统健康状态与同步任务表（严重级别、上次 / 下次运行、落后周期）。同步状态约每 60 秒刷新。

## 关键字段 / 筛选 / 操作
- 摘要指标：待录成本、SPU 总数、已注册店铺总数。
- 店铺表列：店铺、店铺 ID、地区、平台。
- 同步：任务名、周期、上次 / 下次、状态（成功 / 失败 / 运行中）、严重级别（正常 / 落后 1 个周期 / 红灯落后 ≥2 个周期 / 未知）。
- 若有枚举映射权限，摘要区提供「枚举映射管理」入口。
- 本页无写操作。

## 空态 / 错态
- 各区块独立展示加载中、加载失败与重试（冷却期内不可重试）。
- 无店铺、总数未知时，摘要范围文案分别为「无店铺」「全店铺（总数未知）」。

## 验收要点
- 只读角色看不到其无权进入的快速导航（如采购、店铺、运行配置、拦截配置）。
- 同步严重级别沿用服务端结果，前端不改口径。

## 缺口
无本页专属空壳。同步任务列表反映当前注册表；已停调度的任务不应再被理解为「控制台会显示它们正在跑」。

## 现状附录
- 路由：`/v2/pages/dashboard`。读取店铺列表、coverage、healthz、sync/status。
