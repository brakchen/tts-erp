# 运行配置

## 目的
管理版本化的运行时配置和加密凭证引用（例如监控插件可订阅的远端策略）。修改确认发布后才会被业务读取。

## 角色
打开本页在策略上要求 **readwrite**。只读账号即使被授予页面权限，实际也可能打不开。凭证明文不回读。

## 主流程
1. 在列表中查看配置、生效版本、草稿状态。
2. 新建配置（创建本身不会新增业务功能，需已有业务接入读取）或进入工作区编辑 JSON 草稿并暂存。
3. 检查并发布（可填写发布说明）；或从发布历史带入内容后再检查发布。
4. 管理凭证：新增 / 更新 / 归档，不回读明文。

## 关键字段 / 筛选 / 操作
- 列表列：配置、生效状态、草稿状态、更新时间、查看与修改。
- 工作区：当前已发布版本、草稿编辑、检查并发布、发布历史、停用 / 恢复（若提供）。
- 新建：配置名称、配置键、初始内容；校验规则创建后不可改。
- 凭证表：引用、指纹、更新时间、状态。

## 空态 / 错态
- 无读写权限时明确提示联系管理员。
- 版本已变化须查看最新内容再重新检查。离开未保存输入会提示。提交未确认不会自动重放。

## 验收要点
- 未发布草稿不影响当前生效内容。打开页面的档位要求按代码为 readwrite。

## 缺口
无空壳。具体有哪些业务键已接入，以运行中的配置列表为准，不把计划文档中的设想算作已上线能力。
