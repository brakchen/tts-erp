# 视频发布

## 目的
把视频素材排队，经外部设备和发布 worker 发到 TikTok **内容侧**，并核对执行结果。这不是修改店铺订单状态。

## 角色
预置「运营」默认**不含**本页，需单独授予 `page:video-publish`。能进入本页即可使用服务端允许的操作（不按创建人再分权）。API key 访问默认更严。

## 主流程
1. 查看发布配置与设备状态。
2. 选择 MP4、填写发布文案、选择目标设备，确认后上传并加入队列。提交前可编辑；提交后参数锁定。提交前可取消，提交后不能停止。
3. 在任务表按状态筛选（排队 / 执行中 / 失败 / 需核验 / 成功 / 已取消）；可开自动刷新（每 5 秒，隐藏页面暂停）。
4. 按服务端返回的允许操作执行：确认已发布、失败重试、再次核验、重试清理、查看脱敏诊断等。原视频保留，不参与临时副本清理。

## 关键字段 / 操作
- 表列：任务 ID / 版本、状态 / 阶段 / 队列、视频 / 大小、文案、发布 / 核验 / 总执行、Artemis ID、创建者 / 时间、服务端操作。
- 不做：批量或定时发布、Shop Open API 发帖、自动重试、提交后取消或解锁参数。

## 空态 / 错态
- 当前没有运行中或清理中的任务。加载配置 / 任务失败须明确刷新。诊断读取有冷却，不会自动获取。

## 验收要点
- 未获本页授权时页面和相关接口均拒绝。
- 明确告知：成功发布作用在 TikTok 内容侧。

## 缺口
权限设计文档「运营含全部业务页」已落后。抽样未逐条核对全部失败恢复测试夹具，细节以页面允许操作和服务端状态为准。
