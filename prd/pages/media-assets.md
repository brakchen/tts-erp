# 资产管理

## 目的
在公共资产库中上传并整理图片与视频，维护有名称的公共素材包和标签，供数字人和换装使用。

## 角色
系统管理员、运营可进入。写入需 readwrite。预置只读分析默认不能进入。

## 主流程
1. 在「素材包 / 视频 / 全部素材」页签间切换；按名称、说明或标签搜索；全部素材可按图片 / 视频筛选。
2. 上传素材（可本地预览，传输完成须确认入库）。
3. 查看、编辑资料与标签；被素材包或数字人引用时须先解除再删除。
4. 在视频页多选后加入已有包或新建包；在包详情中增删视频。移出后原视频仍留在公共库。仍被任何包引用的资产禁止全局删除。

## 关键字段 / 操作
- 页签与搜索、类型筛选、上传、加入已有包、新建素材包。
- 卡片操作：查看、编辑、删除。包：名称、包内视频、预览、移出。

## 空态 / 错态
- 没有符合条件的素材；包内还没有视频。放弃未保存修改需确认。上传结果未确认须核对是否已入库，不自动当成成功。

## 验收要点
- 数字人档案看到的是同一份公共包，不是各归档本。
- 不把未落地的计划文档功能算进来。

## 缺口
次级弹窗与失败恢复路径按主组件梳理，未逐条对全部测试夹具。

## 现状附录
