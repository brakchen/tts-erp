# 登录

## 目的
让已由管理员分配账号的运营人员，用用户名和密码进入工作台并建立会话。

## 角色
公开页，无需登录。不提供自助注册或找回密码。账号开通与重置请联系管理员。

## 主流程
1. 打开服务端登录页（须带有效返回地址 `next`）。
2. 输入用户名、密码，可显示或隐藏密码，提交登录。
3. 成功则写入会话 cookie，跳转到返回地址或默认运营页。
4. 若结果未确认，可「查询当前会话」做核对；查询成功也不自动视为原密码正确，需明确选择继续使用当前会话或允许手动重新登录。

## 关键字段与操作
- 用户名、密码。
- 按钮：登录；失败或不确定时可查询当前会话。
- 错误统一为「用户名或密码错误」（不区分用户是否存在）。冷却期间不会自动重试。

## 空态 / 错态
- 缺少有效返回地址：提示登录暂不可用，请重新打开服务端登录页。
- 服务暂不可用、限流冷却、查询未完成：保留输入，不自动提交。

## 验收要点
- 布局为左侧品牌区 + 右侧表单，无侧栏。
- 无注册、找回密码入口。
- 登录方式以代码为准：用户名 + 密码，不是 API key 换 cookie。

## 缺口
- 工作台登录后顶栏无「修改自己密码」入口（改密 API 已存在）。
- 仓库 README 仍写 API key 登录，文档落后。

## 现状附录
- 路由：`GET/POST /v2/auth/login`；会话查询 `/v2/auth/me`；退出 `/v2/auth/logout`；改密 `/v2/auth/change-password`（仅 API）。
