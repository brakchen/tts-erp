# 广告日明细

## 目的
浏览插件上报并落入本地的广告日事实，用服务端汇总评估投放。源币种为 USD。

## 角色
系统管理员、运营、只读分析均可进入。本页只读。

## 主流程
1. 按店铺 Seller ID、广告账户、数据接口、日期范围、计划 / 商品 ID（部分匹配）和每页行数设置条件。
2. 应用筛选后阅读「全部筛选结果汇总」（全部匹配行，不只是当前页）。
3. 在明细表中排序、翻页，打开行详情复制 ID 或查看额外采集指标。

## 关键字段 / 筛选 / 操作
- 筛选：店铺 Seller ID、广告账户、数据接口、开始 / 结束日期、计划或商品 ID、每页 25 / 50 / 100 / 200、重置 / 应用 / 刷新。
- 汇总：记录行数、消耗 USD、归因订单、归因 GMV USD、加权 ROI。
- 表列：日期、店铺、计划、商品、消耗 USD、归因订单、归因 GMV USD、源 ROI、最近更新、详情。

## 空态 / 错态
- 暂无广告日数据；筛选项或列表读取失败须手动重试。
- 开始日晚于结束日应提示校验错误。

## 验收要点
- 汇总范围是全部筛选结果，不是当前页相加。
- 不把本页金额当成盈利页的 CNY 结果；盈利侧广告消耗会按汇率快照换算。

## 缺口
- 广告「会话分析」未启用，本页不包含该集合。
- today→daily 固化任务已停；日数据依赖插件现行 T-1 路径。
