# 授权结果页

## 目的
展示 OAuth 回调或其他辅助流程的完成结果（成功、警告或失败），必要时给出一次性授权链接和跳转。

## 角色
无侧栏。回调与拒绝结果必须在没有已登录会话时仍可阅读。前端资源缺失时，服务端直出的 HTML 仍应可读。

## 主流程
1. 阅读标题、说明和语调（成功 / 警告 / 危险 / 默认）。
2. 若带授权链接：查看有效期，打开授权页面（链接单次有效）。
3. 若有分节事实表，按「项目 / 内容」阅读。
4. 按结果选择行动：前往店铺注册台、返回登录页，或重新开始授权（回到说明跳板，而不是在本页重做向导）。

## 关键字段
- 标题、说明、可选授权 URL 与有效期、可选事实分节、行动按钮。

## 空态 / 错态
缺少页面数据时前端不应臆造结果。失败语调须保留，不能被资源加载失败覆盖成空白成功页。

## 验收要点
- 不把本页做成需登录才能看见的工作台页。
- 行动只有既定三种，不在此页改店铺配置。

## 缺口
`page-loader.ts` 未注册 message 模块，结果页以服务端直出为主，JavaScript 仅用于展示已完成的结果。这是实现形态，不是缺失的业务功能。

## 现状附录
- 由授权回调等服务端渲染；行动路径对应店铺页、登录页、`/v2/oauth/tiktok/onboard`。
