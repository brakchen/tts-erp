# 枚举映射

## 目的
把上游英文枚举翻译成页面使用的中文标签，让业务数据使用同一种语言。

## 角色
系统管理员、运营可进入页面。**增删改实际要求 admin**（页面文案与接口一致）。`PAGE_MIN_WRITE_TIER` 写成 readwrite 与实现不符，以 handler 为准。

## 主流程
1. 按分类查看映射（订单状态、售后类型 / 状态、结算组件、成本来源、物流状态、表头翻译等）。
2. 管理员新增、编辑或删除映射。英文值创建后只读；相同分类和英文值已存在时更新中文标签与排序。
3. 显示顺序以服务端返回为准。

## 关键字段 / 筛选 / 操作
- 筛选：分类。操作：新增映射、刷新映射。
- 表列：英文值、中文标签、排序、编辑 / 删除。
- 表单字段：分类、英文值、中文标签、排序（非负整数）。

## 空态 / 错态
- 该分类暂无映射。列表不可用时可重试。维护按钮对非 admin 提示权限不足。

## 验收要点
- 非 admin 不能保存或删除。只按登记表给运营 write 时，保存应被服务端拒绝。

## 缺口
登记表与真实限制不一致，见总册第 5 条。
