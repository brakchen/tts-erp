# 采购工作台

## 目的
按店铺核对货源价与人工采购成本。人工价是盈利计算中最高优先级的成本来源。

## 角色
系统管理员、运营可进入。只读分析默认不能进入。浏览不需写入；提交成本需要 readwrite。

## 主流程
1. 选择店铺，切换视图：全部 SPU / 缺成本候选 / 最近提交。
2. 按需搜索、按状态（在售 / 下架 / 停售）筛选，勾选仅看有单、仅看未登记、仅看本页缺图，并设置排序。
3. 在表格中查看当前人工成本、货源价（仅供参考）和本地镜像主图。
4. 编辑草稿（单位成本、货币、备注、生效时间），关闭弹窗会保留草稿；确认后逐行提交。也可「提交本页已编辑行」（各行独立事务，可中途停止后续行）。
5. 在「最近提交」查看变更前后并跳回当前商品。

## 关键字段 / 筛选 / 操作
- 视图与筛选见上。排序字段：状态、成本、创建时间、更新时间；升序 / 降序。
- 表列（商品）：内部 PK / SPU、标题 / 状态、当前人工成本 / 货源价、创建 / 更新、图片、操作。
- 表列（最近提交）：记录 / PK / SPU、标题、变更前、变更后、备注、生效 / 结束、提交时间、查看当前商品。
- 生效时间留空则使用服务端当前时间；指定时需带时区的 ISO 时间。货币与金额对应，页面不换算。

## 空态 / 错态
- 暂无可选店铺、当前页暂无候选、暂无提交记录。
- 服务拒绝写入（403）时草稿保留。提交未确认须先查询当前事实，再决定是否重新提交（会新增历史）。

## 验收要点
- 只读可看不可改。批量提交不扩大到其他页或其他店铺。
- 成本优先级在盈利中为：人工价 > 妙手货源价 > 40 CNY/件兜底。

## 缺口
无本页空壳。成本快照另有 API 但无独立运营页。
